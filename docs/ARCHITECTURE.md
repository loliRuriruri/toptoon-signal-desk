# TOPTOON Signal Desk 동작 구조

이 문서는 로컬 실행판과 Cloudflare 공개판이 어떻게 데이터를 만들고 보여주는지 설명합니다. 두 환경은 같은 UI 코드를 사용하지만 권한과 데이터 갱신 책임이 다릅니다.

## 1. 전체 흐름

```text
TOPTOON 공개 API 4개 ─┐
원본 Tracker Worker ──┼─> 로컬 수집/정규화 ─> 교차검증 ─> data/*.json + data/*.js
OpenDART/KIS/FRED ─────┘                              │
                                                     ├─> 로컬 서버 UI
                                                     └─> 공개 허용 빌드
                                                          │
                                                          └─> Cloudflare Pages
```

금융 API 키를 보유한 로컬 PC가 데이터 생산자입니다. Cloudflare Pages는 검증을 통과해 업로드된 결과를 제공하는 읽기 전용 배포처입니다.

## 2. 브라우저 애플리케이션

`index.html`, `styles.css`, `app.js`로 구성된 프레임워크 없는 단일 페이지 앱입니다. 별도 번들러 없이 브라우저에서 바로 실행되며 다음 화면을 제공합니다.

- 사업 요약: 매출 넛캐스트, 캐릭터 TOP 6, 지역별 대화 구성, 공급·반응 변화
- 공시·주가 검증: OpenDART 공시, 확정 재무실적, KIS 시세, 장중 가격 범위, 시장조치, 피어 비교, 자동 QA
- 캐릭터: 한국·일본·글로벌·대만 통합 검색, 정렬, 작품 후보, 이미지와 공식 모션 상세
- API 설정: 로컬판에서만 표시되는 키 상태·OpenRouter 분석·수동 배포 제어

브라우저는 `data/*.js`에 포함된 `window.TOPTOON_*` 객체를 읽습니다. JSON 파일은 감사와 재가공용이고 JS 파일은 `file://`이 아닌 일반 정적 호스팅에서도 별도 API 서버 없이 데이터를 읽기 위한 런타임 번들입니다.

## 3. 데이터 수집과 검증

### 공개 캐릭터 데이터

`scripts/refresh-public-snapshot.mjs`가 네 시장의 공개 캐릭터 목록을 수집하고 필드를 공통 형식으로 정규화합니다. 캐릭터 이미지는 시장별 폴더에 저장하며, 원본 비율을 유지한 전체 이미지와 공식 소개 모션 URL을 레코드에 연결합니다. `oneLineIntro`, `detailedIntro`, `customWorldSummary`, 해시태그도 공개 카탈로그 원문으로 저장해 상세 프로필의 소개 패널에 사용합니다.

공식 상세 페이지의 댓글 API는 사용자 생성 콘텐츠이며 공개 Pages 원본에서 CORS로 직접 읽을 수 없습니다. 따라서 댓글·닉네임·회원 ID를 스냅샷에 복제하지 않고, 상세 프로필에서는 공식 페이지의 댓글 링크만 제공합니다. 댓글을 별도 서버 프록시로 노출하려면 서비스 약관·개인정보·삭제/신고 처리와 별도 접근제어를 먼저 검토해야 합니다.

### 교차검증

`scripts/crosscheck.mjs`는 저장 스냅샷과 재조회 값을 비교합니다. 시장별 목록 수, 누적 채팅·조회수 차이, 이미지 참조, 계산식, 공시 연결 한계를 `data/validation.*`에 기록합니다. 누적값은 수집 중에도 늘 수 있으므로 작은 시차는 정상으로 표시하고, ID 중복이나 이미지 누락은 별도 무결성 문제로 취급합니다.

### 공식 금융 데이터

`scripts/refresh-official-signals.mjs`는 다음 자료를 갱신합니다.

- OpenDART: 탑코미디어 `134580`의 회사 고유번호를 찾은 뒤 최근 공시 조회
- 한국투자증권 KIS: 현재가, 전일종가, 등락부호, 시가·고가·저가, 거래량, 상장주식수, 시가총액, PER/PBR과 피어 시세
- FRED: 환율 보조 지표

KIS 등락률은 `현재가 대 전일종가`입니다. 장중 저점 대비나 시초가 대비 상승률과 구분하기 위해 UI에 비교 기준과 OHLC를 함께 표시합니다. 저장된 KIS 캐시는 요청한 종목코드가 같은 경우에만 재사용됩니다.

## 4. 로컬 실행판

`scripts/serve.mjs`가 `127.0.0.1:8788`에 HTTP 서버를 띄웁니다. 정적 UI 외에 다음 로컬 전용 엔드포인트를 제공합니다.

- API 연결 상태 확인과 `.env.local` 설정 변경
- OpenRouter 보조 분석 실행
- 갱신·검증·공개 빌드·배포 작업 시작 및 진행 상태 확인
- 공식 TOPTOON 모션의 제한형 미디어 프록시

키 원문은 상태 응답이나 HTML/JS 데이터에 포함되지 않습니다. 로컬 설정 화면도 저장된 키 값을 다시 표시하지 않고 설정 여부만 보여줍니다.

`TOPTOON-Tracker.cmd` 또는 `scripts/launch.ps1`이 서버를 시작하고 브라우저를 엽니다. `-Refresh`를 사용하면 화면을 열기 전에 데이터 수집을 수행합니다.

## 5. 공개 배포판

`scripts/build-public.mjs`는 프로젝트 전체를 업로드하지 않습니다. 공개에 필요한 HTML, CSS, JS, 정제된 데이터, 중복 제거 이미지, 보안 헤더, `public-worker.js`만 `dist-public`에 만듭니다.

공개판에서 제거되는 기능은 다음과 같습니다.

- API 설정 화면과 키 저장
- OpenRouter 호출
- 로컬 배포 버튼과 진행 상태 API
- 로컬 파일 및 실행 로그 접근

`public-worker.js`는 공식 TOPTOON `video-thumbnail` MP4 주소만 규칙으로 검증해 스트리밍합니다. 이는 브라우저의 미디어 요청 제약을 완화하기 위한 것이며 범용 프록시가 아닙니다.

## 6. 자동 및 수동 배포

`scripts/update-and-deploy.ps1`은 다음 단계를 순서대로 실행합니다.

1. 네 시장과 원본 통계 갱신
2. 라이브 교차검증
3. OpenDART·KIS·FRED 갱신
4. 데이터와 JavaScript 검증
5. 공개판 빌드
6. 비밀정보 패턴 검사
7. Cloudflare Pages 운영 배포

어느 검증 단계든 실패하면 배포 단계로 진행하지 않습니다. 로컬 실행기의 수동 배포 버튼도 동일 스크립트를 호출합니다.

`scripts/install-auto-update-task.ps1`은 이 스크립트를 Windows 작업 스케줄러에 등록합니다. PC가 꺼지면 새 데이터 수집만 멈추고 이미 배포된 Cloudflare 사이트는 계속 서비스됩니다. PC가 다시 켜지고 예약 작업이 실행되면 최신 스냅샷으로 갱신됩니다.

## 7. 보안 경계

- 실제 키는 `.env.local`에만 저장하고 Git에서 제외합니다.
- 공개 빌드는 허용 목록 방식으로 만들고 배포 전에 비밀정보를 검사합니다.
- 로컬 관리 API는 루프백 주소에서만 사용합니다.
- 대시보드의 LLM 분석에는 요약된 수치와 텍스트만 보내며 캐릭터 이미지와 API 키는 보내지 않습니다.
- 조회수·채팅수·가정 환산액을 실제 매출이나 투자 성과로 표현하지 않습니다.

## 8. 주요 파일

| 경로 | 역할 |
| --- | --- |
| `app.js` | 화면 렌더링, 검색·정렬·상세·검증·피어 UI |
| `styles.css` | 반응형 레이아웃과 시각 디자인 |
| `data/characters.*` | 네 시장 캐릭터 스냅샷 |
| `data/stats.*` | 원본 Tracker 통계 스냅샷 |
| `data/validation.*` | 교차검증 결과와 투자 증거 경계 |
| `data/official-signals.*` | 비밀정보를 제거한 공식 API 결과 |
| `scripts/serve.mjs` | 로컬 정적 서버와 관리 API |
| `scripts/update-and-deploy.ps1` | 전체 갱신·검증·배포 오케스트레이션 |
| `scripts/build-public.mjs` | 공개 허용 파일 빌드와 비밀정보 검사 |
| `public-worker.js` | Cloudflare Pages 제한형 미디어 프록시 |
