# Page topology

## Source snapshot

- URL: `https://toptoon-tracker.john6428.workers.dev/`
- Captured: 2026-08-24 at 1440 px, 768 px, and 390 px.
- Original shell: sticky header, compact controls, stacked dark panels, canvas charts, a character table, and a detail modal.
- Original navigation: Main, DC Gallery, Global Entry.

## Rebuild topology

1. Sticky application header
   - title and current-snapshot note
   - primary region tabs: 통합, 한국, 日本, Global
2. Market overview panel
   - four summary cards
   - market comparison chart in 통합
   - top-character chart in a single-market tab
3. Character browser panel
   - text search, work filter, sort control, result count
   - desktop table and compact mobile cards
4. Character detail dialog
   - local thumbnail, name/work, views/chats
   - presence and localized names for all available markets
   - explicit outbound detail links
5. Data note/footer
   - extraction date and public-data scope

The rebuild deliberately does not invent unavailable historical, revenue, or DC Gallery data. It turns the verified three-market snapshot into the primary product surface.
