# Taiwan page topology

- Public origin: `https://chat.toptoon.net/`
- Catalog API: `GET /api/characters?limit=100`
- Character route: `/detail/character/{id}`
- 2026-08-24 public count: 81 characters in one page.
- Character IDs align with the Korean, Japanese, and Global services.
- Public navigation: Home, Explore, Ranking, Chats, Favorites, Collection, Attendance, Settings.

The unified tracker only reproduces the public catalog relationship and links back to each official character detail page. Login, chat, favorites, albums, comments, and paid interactions stay on the official service.
